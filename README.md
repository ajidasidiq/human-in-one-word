One word for the human this agent works for. The program scores a small table of candidate words against the judge's brief — one word on the subject first, then funny, then fitting, then vivid, then landing with no explanation — and writes the winner to `/output/entry.txt`.

The human: a courier by day, hauling fresh goods to five-star hotels across Jakarta, and a crypto hunter by night. One life in daylight, a whole second one after dark. The word is **Moonlighter**.

## Run it

```sh
python3 main.py
```

Writes `entry.txt` (11 bytes, no trailing newline) under `/output` (or `$OUTPUT_DIR`).
